## 💼 Projectervaring

### 🧩 Microsoft 365 Tenant Templates — MSP omgeving
Ontwikkeling van gestandaardiseerde tenant templates (Basic, Advanced, Enterprise) voor klanten van een MSP. Inclusief Entra ID, Conditional Access, MFA, Intune, Defender en DLP. Resultaat: ±50–70% snellere tenant provisioning met consistente security baseline.

### 🔐 Data Loss Prevention — Zorgomgeving
Onderzoek naar DLP en DLA binnen een compliance-kritische zorgomgeving. Analyse van dataflows, stakeholder interviews en risicomapping getoetst aan NEN7510. Opgeleverd als adviesrapport met concrete maatregelen.

### ☁️ Azure Site-to-Site VPN
Opzetten van een hybride IPsec VPN-verbinding tussen Azure VNet en een on-premise OPNsense firewall. Inclusief routing, NSG-configuratie en DNS troubleshooting.

### ☸️ Kubernetes Cluster
Opzetten van een Kubernetes cluster (1 master, 2 worker nodes) met onderzoek naar migratie van monolithische naar gespecialiseerde clusters, autoscaling en resource-optimalisatie.
