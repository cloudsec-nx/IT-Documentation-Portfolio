# 📁 IT-Documentation-Portfolio

> Persoonlijk kennisportfolio met generieke IT-documentatie, opgebouwd vanuit de praktijk als Support Engineer.  
> Alle documenten zijn geschreven als SOP, Handleiding of Procedure op basis van een universeel sjabloon.

---

## 📌 Doel van deze repository

Deze repository dient als:
- 📚 **Kennisbank** — vastleggen van wat ik leer in de praktijk
- 🛠️ **Referentiemateriaal** — herbruikbare procedures en handleidingen
- 🚀 **Portfolio** — aantonen van technische en documentatievaardigheden
- 📈 **Groeipad** — van Support Engineer naar Security- of Cloud Engineer

---

## 📂 Mappenstructuur

| Map | Inhoud |
|---|---|
| `Templates/` | Universeel sjabloon voor alle documenttypes |
| `Support-Engineering/` | Windows, M365, Monitoring, Backup, SSL, Ticketing |

| `Assets/` | Diagrammen, Screenshots, Checklists |

---

## 📄 Documentatiestandaard

Elk document in deze repository volgt hetzelfde universele sjabloon met de volgende vaste onderdelen:

1. Voorblad & documentbeheer
2. Doel & toepassingsgebied
3. Definities & afkortingen
4. Rollen & verantwoordelijkheden
5. Benodigdheden
6. Stappen / procedure
7. Uitzonderingen & probleemoplossing
8. Gerelateerde documenten & bijlagen
