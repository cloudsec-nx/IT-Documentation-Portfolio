## 🥇 Certificaat 1 — AZ-900: Azure Fundamentals

### Algemene info
| Veld | Info |
|---|---|
| **Uitgever** | Microsoft |
| **Niveau** | Beginner |
| **Examenduur** | 60 minuten |
| **Examenvorm** | Multiple choice, case studies |
| **Slagingspercentage** | 700/1000 punten |
| **Kosten examen** | ~€120 (via werkgever) |
| **Geschatte studietijd** | 2-4 weken |
| **Examenprovider** | Pearson VUE |

### Waarom als eerste
- Legt de basis voor zowel het Cloud als Security pad
- Volledig gratis te leren via Microsoft Learn
- Gezien mijn hands-on ervaring met Azure, Entra ID, Defender en Intune is dit haalbaar in **1-2 weken**
- Vereiste voor AZ-104 en SC-900

| Week 1 (mei) | Azure compute & storage services | Microsoft Learn | Medium — al ervaring | ⬜ |
| Week 1 (mei) | Azure netwerk services | Microsoft Learn | Laag — al ervaring met VNet, VPN, NSG | ⬜ |
| Week 2 (mei) | Azure beheer & governance | Microsoft Learn | Hoog | ⬜ |
| Week 2 (mei) | Kosten & SLA's | Microsoft Learn | Hoog | ⬜ |

## 💡 Tips

- **Maak een Microsoft Learn account** — je kunt voortgang bijhouden en gratis oefenassessments doen
- **Plan je examen vooraf** — een deadline geeft motivatie
- **Leg studienotities vast** in `Studienotities/Certificeringen/` in je repository
- **Vraag je werkgever** om MeasureUp licentie — oefenexamens zijn de beste examenvoorbereiding
- **Doe de gratis practice assessment** op Microsoft Learn voordat je begint — zo weet je wat je al kent
